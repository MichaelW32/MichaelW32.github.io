01 Project Overview

Abstract

This ongoing project investigates whether deliberate selection of training samples can improve data efficiency in aerodynamic prediction. The proposed study uses existing simulation data from BlendedNet to compare random selection with strategies that prioritize uncertain predictions and diverse aircraft geometries. At each data budget, the same prediction task and held-out test geometries will support a controlled comparison. The project currently focuses on experimental design. Model training and quantitative results remain future work.

Motivation

A surrogate model learns the relationship between aircraft geometry, flight conditions, and an aerodynamic output. This project asks which available training examples contribute most to predicting drag when only a limited number of labels can be used.

The experiment will reveal existing CFD labels progressively. It evaluates data selection without requiring a new CFD simulation for every acquisition step.

02 Research Question

Can uncertainty and geometry diversity guide sample selection to reach similar drag-prediction accuracy with fewer labeled examples than random selection?

Working hypothesis

A selection strategy that combines uncertainty with coverage of the design space may reduce prediction error at a fixed label budget. This is a hypothesis to test. The comparison may also show that random selection performs equally well or better.

Initial scope

The starting task is scalar drag prediction using existing labels. The exact target field, input representation, and eligible simulation cases will be finalized during the data audit. Full surface-field prediction and new CFD generation are outside the initial experiment.

03 Data Source

The planned source is the original BlendedNet dataset introduced by Sung et al. [1]. Its paper reports 999 blended wing body geometries and 8,830 converged CFD cases across multiple flight conditions. These are published dataset counts, not the size of a training set assembled for this project.

04 Proposed Methodology

The experimental design builds on Idea 3 from my project ideas presentation [3]. The methods below describe the planned comparison.

4.1   Common prediction task

Define one drag target and input representation, then use the same model family, initial labeled set, and acquisition budgets for each selection strategy. Fit preprocessing on training data only.

4.2   Sample selection strategies

Table 2. Proposed selection comparison.
StrategySelection rulePurpose
RandomSample eligible examples at randomBaseline
UncertaintyPrioritize candidates with high estimated predictive uncertaintyAssess the value of uncertainty-guided acquisition
Uncertainty + diversityPrioritize uncertain candidates while avoiding redundant geometriesAssess whether broader design-space coverage helps

The uncertainty estimator and diversity measure will be chosen after a baseline model and data representation are established.

4.3   Acquisition loop

  1. Train a surrogate on the currently revealed labels.
  2. Score candidates in the remaining acquisition pool without accessing their hidden target values.
  3. Select the next batch and reveal its existing CFD labels.
  4. Retrain and record test error at the new data budget.
Data separation. Keep test geometries outside the acquisition pool. Use validation data for model and acquisition choices, and reserve the fixed test set for evaluation.

05 Evaluation Plan

The primary comparison will use drag-prediction error at equal label budgets, following the validation plan in the presentation. Repeated random seeds will help assess whether an apparent gain is consistent.

Table 3. Planned evaluation outputs.
OutputQuestion addressed
Test MAE and RMSEHow accurately does each strategy predict drag at a given budget?
Learning curvesHow does held-out error change as labels are revealed?
Budget to reach a target errorDoes a strategy achieve comparable accuracy with fewer labels?
Variation across seedsIs the comparison sensitive to initialization or the initial labeled set?

Results will be reported once the dataset audit, baseline training, and acquisition experiments are complete.
