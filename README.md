# Michael Wang — Engineering Portfolio

Static portfolio website containing a personal homepage, résumé, and ME 370 and ME 498 project pages.

## GitHub Pages

Publish the `main` branch from `/ (root)` in **Settings → Pages → Deploy from a branch**. The `.nojekyll` file keeps the existing HTML, CSS, JavaScript, video, and PDF files unchanged.

## Contents

- `index.html`: personal homepage
- `me370.html`: TerraTrek project
- `me498.html`: aerodynamic prediction project
- `resume.pdf`: résumé

All internal paths are relative, so the website supports either a user site or a project site.
